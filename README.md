SIDOVI "SISTEMA DE INFORMACION PARA LA DOCUMENTACION Y VINCULACON DE NUEVO PERSONAL"

DESCRICION: 

SIDOVI es una aplicación web orientada a la gestión integral del proceso de reclutamiento, selección y contratación de personal en la empresa de seguridad privada, COLVISEG.

El sistema tiene como propósito principal digitalizar y optimizar el proceso de vinculación laboral, permitiendo una administración eficiente, organizada y segura de la información de los postulantes desde el momento de su registro hasta su contratación como trabajador activo.

SIDOVI integra tres tipos de usuarios principales:

Postulante: quien se registra en la plataforma, completa su perfil y carga los documentos requeridos para aplicar a una vacante.

Recursos Humanos (RRHH): encargado de validar la documentación, gestionar el proceso de selección y realizar la vinculación laboral mediante la generación de contratos.

Gerente Regional: responsable de evaluar a los candidatos a través de entrevistas y formularios de evaluación, determinando si el aspirante es apto para el cargo.

El sistema permite realizar funciones como:

Registro y autenticación de usuarios.
Carga y validación de documentos.
Visualización de postulaciones.
Evaluación de candidatos mediante entrevistas.
Consulta de hojas de vida (HDV).
Generación de contratos laborales.
Activación de trabajadores dentro de la empresa.

Además, SIDOVI organiza el flujo del proceso de selección de la siguiente manera: el postulante se registra, carga sus documentos, RRHH valida la información, el gerente realiza la evaluación, y en caso de aprobación, se procede a la vinculación laboral mediante la generación del contrato.

Este sistema contribuye a mejorar la trazabilidad de la información, reducir tiempos operativos y garantizar mayor control en la gestión del talento humano, convirtiéndose en una herramienta clave para la modernización de los procesos de recursos humanos en empresas de seguridad.

INTALACIÓN:

SIDOVI es una aplicación web de uso sencillo, por lo tanto no requiere instalación compleja. El usuario solo necesita acceder desde un navegador web.

Requisitos del Usuario:

Para utilizar SIDOVI, el usuario debe contar con:

Un computador o dispositivo móvil.
Conexión a internet (si está en línea) o acceso a los archivos del sistema.
Un navegador web actualizado:Google Chrome, Microsoft Edge, Mozilla Firefox

  
Acceso al Sistema
 Desde enlace web (si está publicado)

1. Abrir el navegador.
2. Ingresar la dirección web proporcionada por la empresa.
3. Presionar Enter.
4. Se mostrará la pantalla de inicio de SIDOVI.

Inicio de Sesión

1. En la pantalla principal, seleccionar el botón Ingresar.
2. Digitar:
   * Usuario
   * Contraseña
3. Hacer clic en Iniciar sesión.


USO DEL SISTEMA:

Una vez dentro, el sistema mostrará diferentes opciones según el tipo de usuario:

Postulante
* Registrar datos personales.
* Subir documentos.
* Consultar estado de postulación.

Recursos Humanos
* Validar documentos.
* Gestionar postulantes.
* Generar contratos.
* Activar trabajadores.

Gerente Regional
* Visualizar postulaciones.
* Revisar hoja de vida (HDV).
* Evaluar candidatos.
